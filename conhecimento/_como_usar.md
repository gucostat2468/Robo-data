# Como usar a pasta conhecimento

Coloque aqui arquivos **.md** (Markdown) com o conhecimento da empresa: glossário, regras de negócio,
como ler cada indicador, contatos de quem gera cada planilha, padrões de nome de arquivo.

- Cada título (`## Título`) vira um verbete que o canal consegue encontrar.
- Escreva títulos claros, com as palavras que você usaria para perguntar.
- Arquivos que começam com `_` (como este) são ignorados pela busca.
- Tudo é lido no seu computador: nada vai para a internet.

Manuais de cada pessoa da equipe ficam em `agentes/<id>.md` e também são consultados pelo canal.
